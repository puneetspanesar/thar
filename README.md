# Thar website

Static site. Every page is plain HTML in its own folder, with shared styles in `assets/site.css` and scripts in `assets/site.js`.

## Hosting

Works on GitHub Pages, Netlify, Vercel or any static host. On GitHub Pages: Settings > Pages > Deploy from branch `main`, folder `/`. The `CNAME` file points the site at thar.co.

## Forms

Forms send to hello@thar.co through FormSubmit. The first submission triggers a one-time confirmation email to that address.
