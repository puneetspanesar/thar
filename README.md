# Thar website

Static site. Every page is plain HTML in its own folder, with shared styles in `assets/site.css` and scripts in `assets/site.js`.

## Hosting

Works on GitHub Pages, Netlify, Vercel or any static host. On GitHub Pages: Settings > Pages > Deploy from branch `main`, folder `/`. The `CNAME` file points the site at wearethar.com.

## Forms

Forms are delivered through FormSubmit. The first submission triggers a one-time confirmation email to the receiving inbox.

## Analytics and SEO

Google Analytics 4 (G-X071PG53KM) with Consent Mode: visitors in the UK and Europe are asked before analytics cookies are set. Events: generate_lead, tool_use, tool_complete, email_click. Every page carries structured data, and the site publishes sitemap.xml, robots.txt, llms.txt and an RSS feed at /insights/feed.xml.
